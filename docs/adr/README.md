# Décisions d'architecture

Une fiche par décision, une page chacune. Une décision est datée et n'est jamais modifiée : si elle change,
une nouvelle fiche la remplace et indique laquelle elle remplace.

| Fiche | Statut |
|---|---|
| [0001 Base de données](0001-base-de-donnees.md) | À rédiger |
| [0002 Mécanisme de temps réel](0002-temps-reel.md) | À rédiger |
| [0003 Format et destination des logs](0003-journalisation.md) | À rédiger |

Deux fiches facultatives possibles (sujet) : par exemple l'architecture en couches, ou le stockage du jeton côté front.

## Modèle

```markdown
# NNNN Titre

Date : AAAA-MM-JJ · Statut : acceptée | remplacée par NNNN

## Le problème
## Les options
## Ce qu'on a choisi
## Ce que ça coûte
```

Les fiches 0001 à 0003 contiennent seulement les faits à disposition (ce qui est en place dans le code, les options
vues en cours). La rédaction doit être la vôtre : le sujet note 0/3 un dossier écrit par l'IA sans réflexion propre.
